# UA01: Kotlin e Java lado a lado

> Repositório didático: exemplos de lógica e orientação a objetos escritos em Java e em Kotlin, aplicados em sala de aula.

## Sobre o projeto

Material de apoio da **Unidade de Aprendizagem 01**, que apresenta o Kotlin a quem já conhece Java. Cada exemplo foi escrito nas duas linguagens, para comparar a sintaxe lado a lado.

## Contexto acadêmico

Exercício aplicado em sala de aula, usado como prática guiada com os alunos.

## Conteúdo

- `src/logica/`: média de notas com decisão, laço `while`, laço `for` e semáforo com `switch`/`when` (`Exemplo01` a `Exemplo04`, em Java e Kotlin).
- `src/poo/`: orientação a objetos: classes e encapsulamento (`ContaBancaria`), herança (`Funcionario`, `Gerente`, `Desenvolvedor`), polimorfismo e sobrescrita (`calcularSalario`), sobrecarga de métodos (`Calculadora`), classes abstratas (`Forma`, `Circulo`, `Retangulo`) e interfaces (`Pagavel`, `CartaoCredito`, `Boleto`).

## Versões Java e Kotlin

- Este repositório já reúne as duas linguagens: cada arquivo `...Java.java` tem o seu equivalente `...Kotlin.kt`, quando existente.

## Tecnologias

- **Kotlin**
- **Java**
- IntelliJ IDEA

## Como executar

Clone o repositório e abra a pasta no **IntelliJ IDEA**. Cada arquivo com `main` pode ser executado diretamente pelo botão ▶ ao lado da função.

```bash
git clone https://github.com/fabcurvello/UA01_OVA_KOTLIN_JAVA.git
```
